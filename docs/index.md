# HVAC Studio Documentation

HVAC Studio uses Python components, explicit node contracts, and file-based
projects across its desktop workspace, runner CLI, and Python SDK.

| Task | Guide |
| --- | --- |
| Open an example and run a case | [Quick start](user/quick-start.md) |
| Define components, systems, parameters, and model assets | [Modeling](user/modeling.md) |
| Simulate, validate data, calibrate, or optimize | [Workflows](user/workflows.md) |
| Deliver a project and check schema compatibility | [Runtime export](user/export-runtime.md) |
| Choose a runnable reference project | [Examples](user/examples.md) |
| Diagnose a failed run or package | [Troubleshooting](user/troubleshooting.md) |
| Automate runner commands | [CLI reference](user/cli-runner.md) |
| Integrate Python or another engine | [Python SDK](user/python-sdk.md), [engine protocol](user/external-engine-protocol.md) |
| Develop or package the application | [Development](development.md), [architecture](architecture.md), [release](release.md) |

Windows 10/11 x64 is the primary package target. Package support and signing
boundaries are recorded in the [support matrix](legal/support-matrix.md).
